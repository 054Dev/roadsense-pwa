# RoadSense React UI Preview

A responsive React + Vite front-end concept for the RoadSense PWA.

## Run locally
1. Install Node.js (LTS).
2. Extract this folder.
3. Open a terminal in the extracted folder.
4. Run `npm install`
5. Run `npm run dev`
6. Open the local URL printed by Vite (usually http://localhost:5173).

## Included interactions
- Responsive mobile navigation
- Clickable hazard pins and recent detections
- Notification popover
- Dashboard preview modal
- Scroll navigation between sections

## Important
This is a front-end preview using sample hazard data. It does not yet connect to the RoadSense API, database, authentication, or live hardware sensor feed. Integrate the components with the existing app routes and backend before production use.
